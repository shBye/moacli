# 세션 제목

2026-09-08 구현. v0.1.30부터 Windows 설치 파일에 포함된다.

## 사용자 동작

- 새 세션의 기본 선택은 **Automatic (default)** 이다. 처음에는 CLI·폴더 이름을 표시하고, 대화 기록이 연결되면 CLI 제목을 따른다.
- **Custom title**을 선택하면 40자 이내 제목을 직접 입력한다. 빈 제목으로 시작할 수 없다.
- 직접 입력한 제목은 MoaCLI에서 보존한다. CLI의 제목 변경과 관계없이 탭·기록·검색 결과 및 기록에서 다시 열기에 같은 제목을 사용한다.
- PowerShell의 자동 제목은 셸·폴더 이름이다.

## 제목 출처

| CLI | 자동 모드의 우선순위 |
| --- | --- |
| Claude | 기록의 마지막 custom-title → 마지막 ai-title → 첫 사용자 질문 |
| Codex | 계정별 session_index.jsonl의 thread_name → 첫 실제 사용자 질문 → 세션 ID |
| Gemini | 기록의 summary → 첫 사용자 질문 → 세션 ID |

자동 모드는 CLI가 제공한 제목을 읽는 기능이다. MoaCLI가 별도의 모델 호출로 제목을 생성하지 않는다.
Codex 이름 인덱스는 선택적 로컬 메타데이터이며, 파일이 없거나 일부 행이 불완전해도 기존 기록 탐색을 유지한다.
인덱스의 수정 시간·크기로 캐시를 무효화하므로 대화 본문을 수정하지 않은 이름 변경도 다음 기록 조회에서 반영된다.

## 저장 및 경계

사용자와 합의한 MoaCLI 별도 저장 방식이다. CLI 원본 파일이나 이름을 변경하지 않는다.
렌더러 localStorage의 `cli-agent-manager.custom-session-titles`에 기록 키별 제목을 저장한다.
기록 키에는 CLI·계정·기록 경로 식별이 포함되어 다른 계정의 세션과 구분된다.
처음 기록이 연결되기 전에는 실행 중 세션이 제목을 보유한다. 연결되면 저장소에 반영한다.
저장소 접근이 차단되거나 용량이 부족하면 현재 실행의 메모리 제목만 유지된다.

제목 변경은 터미널 ID·resumeId·terminalRevision을 변경하지 않는다.
기록이 일시적으로 조회되지 않아도 현재 제목을 임시 제목으로 되돌리지 않는다.
삭제·경로 이동된 기록의 제목 매핑을 자동 삭제하거나 다른 기록으로 추측해서 이관하지 않는다.

이전 버전에서 이미 종료되어 사라진 사용자 제목은 복원할 수 없다.
검색 결과의 표시 제목에는 적용되지만, 직접 입력한 제목 자체를 SQLite 검색 색인에 추가하지는 않는다.

## 검증

`scripts/session-titles.test.cjs`는 세 CLI의 자동 갱신·사용자 제목 우선순위·재열기,
계정 분리·잘못된 저장 데이터·Codex 인덱스 갱신·Claude 최신 제목 선택을 검증한다.
기존 터미널 생명주기 테스트로 제목 변경 시 PTY 유지 동작을 함께 확인한다.
실제 세 CLI의 모든 버전에서 자동 제목 생성 시점까지 검증한 것은 아니다.
