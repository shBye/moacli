# MoaCLI v0.1.31

## Changes

- Added role-based mini-agent tasks: reviewer, investigator, planner, and designer, with single-level delegation and bounded concurrency.
- Automatically link tasks from MoaCLI-launched Claude and Codex sessions to their original Tasks tab.
- Added manual Git-change previews and snapshot analysis, with findings that can be inserted into the original CLI as a draft.
- Separated automatic approval for analysis and file editing. File-edit auto-approval remains off by default.
- Added richer notifications with task context, short result/error excerpts, and next-action hints. Desktop result previews are opt-in.
- Standardized settings dropdowns and descriptions, improved folder expansion and account visibility, and reduced unnecessary task loading and terminal rendering.

## Notes

- Restart existing CLI sessions to enable automatic task linkage.
- Snapshot analysis requires a Git repository with an initial commit and uncommitted changes. Live CLI usage may consume the selected account's allowance.
- Delegation limits are application-level controls, not operating-system isolation.
- Windows x64 installer. This build is not code-signed; Windows SmartScreen may show an unknown-publisher warning.
