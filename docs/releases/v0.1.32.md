# MoaCLI v0.1.32

- Added automatic local diagnostics for intermittent CLI scroll jumps, including viewport, buffer, resize and scroll-restoration events.
- Added **Save diagnostics** to the bottom status bar to export recent records and incident context.
- Logs are bounded and exclude conversation text, commands, typed characters, project paths and account details. Nothing is uploaded automatically.

This release helps identify the cause of scroll jumps; it does not claim to fix the underlying issue. After a jump, save diagnostics promptly and include the JSON in your report.

Windows x64 installer. This build is not code-signed.
